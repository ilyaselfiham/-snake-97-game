# 🐍 Snake 97 — Classic Nokia Snake Game

A small web-based Snake game inspired by the classic Nokia mobile phone game from the 1990s.

This project was developed using vanilla HTML, CSS and JavaScript, without external libraries or frameworks.

## 🎮 About the Project

The objective is simple: control the snake, eat the food, increase your score and avoid colliding with the walls or the snake's own body.

The project recreates the old Nokia visual experience with a green LCD-style screen and pixel-based graphics.

## ✨ Features

- Classic Nokia-inspired interface
- Snake movement and food generation
- Collision detection
- Score and best score tracking
- Keyboard controls (Arrow keys and WASD)
- Mobile touch and direction-button controls
- Start, pause and restart functionality
- Responsive design

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS3 | Interface and responsive design |
| JavaScript | Game logic and interactions |
| Canvas API | Drawing the snake and game board |
| LocalStorage | Saving the best score |

## 📂 Project Structure

```text
snake-97-game/
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Press START to begin playing.
4. Use the arrow keys or WASD to control the snake.

No installation or additional dependencies are required.

## 🧠 Main Concepts Practiced

- JavaScript functions and variables
- Arrays and objects
- DOM manipulation
- Event listeners
- Game loops using setInterval()
- Collision detection
- Random number generation
- Browser local storage
- Canvas drawing

## 🎯 Project Objective

The objective of this project was to practice JavaScript fundamentals and understand how game logic, user input, rendering and browser storage work together in a simple interactive application.
